Experiment 4: Vpp, Vm and Vrms

Calibrating the oscilloscope against an AC voltmeter and verifying Vm = √2 Vrms

⚠️ Safety: use only the low-voltage AC output of the supply (step-down transformer or variac set below 15 V); never connect the oscilloscope or the meter to the mains directly; switch off before changing connections.

Pre-lab questions

Theory

An alternating voltage changes all the time, so we need special values to describe it. Linked to Chapter 6 – AC sources: Vrms and Irms.

v(t) = Vm sin(2πft)

1. Three values of the same voltage

• Vm (peak or maximum value): the largest value, measured from zero. • Vpp (peak-to-peak): from the top to the bottom of the wave, Vpp = 2Vm; this is what we read on the oscilloscope. • Vrms (root-mean-square or effective value): the DC voltage that would give the same heating in a resistor; this is what an AC voltmeter shows.

Vrms = Vm / √2 = 0.707 Vm  ⇔  Vm = √2 Vrms Vpp = 2Vm = 2√2 Vrms = 2.83 Vrms

2. The graph

Plot Vpp (from the oscilloscope) on the y-axis against Vrms (from the voltmeter) on the x-axis. The result is a straight line through the origin with slope = 2√2 ≈ 2.83. Equivalently, Vm/Vrms = √2 ≈ 1.414.

The oscilloscope (and the voltmeter) is calibrated when the measured ratio agrees with √2. The calibration accuracy is

error % = |(Vm/Vrms) − 1.414| / 1.414 × 100 %

Example: the mains in Saudi Arabia is 220 V rms, so its peak value is 311 V and its peak-to-peak value is 622 V.

Apparatus: low-voltage AC supply (60 Hz) with a variable output (variac or potentiometer), AC voltmeter, oscilloscope, connecting wires.
