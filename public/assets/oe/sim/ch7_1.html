Experiment 1 — Microring resonator: filter and sensor

A silicon microring (neff = 2.4, ng = 4.2) is coupled to one bus (all-pass) or two buses (add-drop). Resonances occur where the round-trip phase is 2πm; their width is set by loss and coupling.

Tap = (a² − 2ra cos φ + r²)/(1 − 2ra cos φ + r²a²), φ = 2πneffL/λ
Tdrop = (1 − r²)²a/(1 − 2r²a cos φ + r⁴a²)
FSR = λ²/(ngL), FWHM = (1 − ra)λ²/(πngL√(ra))
Sensor: Δλ = λ·0.15Δnclad/ng
All-pass and add-drop spectra over two FSRs
Zoom on one resonance: before and after the cladding index change (sensor)

Try this

  1. Compare the numerical FSR and FWHM with the formulas. How does the FSR change when R doubles?
  2. Set r equal to the round-trip transmission a (critical coupling). What happens to the extinction ratio?
  3. For loss 3 dB/cm and R = 10 µm, what is the intrinsic Q? What limits the Q of small rings?
  4. A refractive-index change of 10⁻³ in the cladding: how far does the resonance move? What is the detection limit if you can resolve FWHM/10?

Experiment 2 — Directional-coupler switch (Δβ switching)

A coupler of length L = Lc sends all light to the cross port. An electro-optic phase mismatch Δβ detunes it; at ΔβL = √3π the light returns to the bar port. The coupled-mode equations are integrated with RK4 and compared with the analytic result.

Pcross = (κL)²/[(κL)² + (ΔβL/2)²] sin²√((κL)² + (ΔβL/2)²)
Push-pull: Δβ = (2π/λ)n³r33ΓV/g
LiNbO₃: n = 2.14, r33 = 30.8 pm/V, Γ = 0.5, L = 5 mm, λ = 1.55 µm
Cross and bar power versus ΔβL (dot: current V)
Power along the switch at the current voltage (lines: RK4)

Try this

  1. Find the bar-state voltage for g = 8 µm. Compare ΔβL with √3π.
  2. Set κL = 0.6π (a fabrication error). Can the cross state still be reached? Can the bar state?
  3. Why does a single Δβ section never give a perfect cross state when κL ≠ π/2? How does the reversed-Δβ (two-section) design fix this?
  4. How would you halve the switching voltage?

Experiment 3 — MZI-mesh optical processor

A rectangular (Clements) mesh of N(N − 1)/2 MZIs realises any N × N unitary matrix. Each MZI is T = [eiφcos θ, −sin θ; eiφsin θ, cos θ]. Random phase errors reduce the fidelity F = |Tr(U†U′)|²/N².

MZIs: N(N − 1)/2, phase shifters N(N − 1) (+ N output)
Clements depth N; Reck depth 2N − 3
Fidelity F = |Tr(U†U′)|²/N²

Try this

  1. Count the MZIs and phase shifters for N = 8 and N = 64 (as in Lab 7.3).
  2. Compare the worst-path loss of rectangular and triangular meshes for N = 16 at 0.2 dB per MZI.
  3. At σ = 0.02 rad, how does the fidelity fall with N? Explain why larger meshes need calibration.
  4. Check the unitarity card: why is |U†U − I| ≈ 10⁻¹⁵ for a lossless mesh?
