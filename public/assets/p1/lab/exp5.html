Theory

Linked to Chapter 8 — Current and Resistance (resistors in series and parallel) of the lectures. Each resistor obeys Ohm’s law, Vi = Ii Ri.

1. Series connection — one path for the current

The resistors are joined end to end. No charge piles up, so the same current passes through every resistor, and the supply voltage is shared:

I = I1 = I2 = I3 = I4 V = V1 + V2 + V3 + V4 Req = R1 + R2 + R3 + R4

Req is larger than the largest resistor. If one resistor is removed the circuit is broken and all current stops.

2. Parallel connection — several paths (a “current splitter”)

Each resistor is connected directly across the same two points, so each has the same voltage, and the main current divides between the branches:

V = V1 = V2 = V3 = V4 I = I1 + I2 + I3 + I4 1/Req = 1/R1 + 1/R2 + 1/R3 + 1/R4

Req is smaller than the smallest resistor. Removing one branch does not stop the current in the others.

3. Measuring Req

Req, exp = Vtotal / Itotal % difference = |Req, exp − Req, th| / Req, th × 100 %
Apparatus: DC supply (6 V), four resistors in sockets (100 Ω, 220 Ω, 330 Ω, 470 Ω, ±5 %), milliammeter, voltmeter, switch, leads.
