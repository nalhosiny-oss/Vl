Theory

1. Every measurement has an uncertainty

No quantity can be measured perfectly. We report a result as x = xavg ± Δx with a unit. For a single reading on a scale, take Δx = ½ of the smallest division (a millimetre ruler gives ±0.5 mm).

2. Types of error

Systematic errors shift every reading the same way (a balance that is not zeroed, measuring from the worn end of a ruler). They are removed by correcting the method. Random errors scatter the readings above and below the true value; they are reduced by repeating and averaging. Accuracy = how close a result is to the accepted value; precision = how close repeated results are to each other.

3. Mean, standard deviation and percentage error

xavg = Σxi / N σ = √[ Σ(xi − xavg)² / (N − 1) ] % error = |x − A| / A × 100%

4. Propagation of uncertainty

z = x ± y : Δz = √(Δx² + Δy²) z = xy or x/y : Δz/|z| = √[(Δx/x)² + (Δy/y)²] z = xn : Δz = |n| xn−1 Δx z = c x : Δz = |c| Δx

5. Significant figures and rounding

Round the uncertainty to one (or two) significant figures, then round the value to the same decimal place: 2.593 ± 0.03 cm → 2.59 ± 0.03 cm.

6. Straight-line graphs

Put the quantity you control (independent variable) on the x-axis and the measured response on the y-axis. Choose a scale that uses most of the graph paper, plot the points, then draw one best straight line (not “connect the dots”) with about equal numbers of points above and below it. Read two points on the line that are far apart:

slope m = (y2 − y1) / (x2 − x1) y = m x + b
